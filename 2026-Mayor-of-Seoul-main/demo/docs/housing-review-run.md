# 주거 공약 기사 검증 실행

Windows PowerShell에서 압축을 푼 프로젝트의 `demo` 폴더를 엽니다. 다음 명령을 순서대로 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

[주거 공약 기사 검증 화면](http://127.0.0.1:8000/housing-review)을 엽니다. 개표 모의 송신 서버는 이 검증 화면에 필요하지 않습니다.

1. **정상**을 선택하고 검증한 뒤 검토자 이름을 입력해 승인합니다.
2. **출처 누락**을 선택해 검증합니다. 첫 번째 문장에 차단 사유가 표시됩니다. 반려 사유를 입력해 반려합니다.
3. **AI 판정 불일치**를 선택해 검증합니다. 제공된 근거 대조는 통과하지만 시연용 AI 판정 값이 다르므로 승인이 차단됩니다.
4. 페이지를 새로고침해 검증·승인·반려 결과가 남아 있는지 확인합니다.

검증은 제공된 7문장과 근거 자료를 기준으로 수행합니다. 새 기사에 대한 사실 판정이나 외부 AI 호출은 포함하지 않습니다. 검토자 이름은 직접 입력하는 시연용 필드입니다.

기록은 방송 서버의 `housing-review.sqlite3`에 저장됩니다. `HOUSING_REVIEW_DB` 환경변수로 경로를 지정할 수 있습니다. 같은 방송 서버에 연결한 브라우저가 같은 이력을 봅니다. 저장소 접근이나 실제 검토자 권한 관리는 팀 배포 환경에서 별도로 구성해야 합니다.
